# P1-T04：PC 接入向导与真实源码工作台

将本卡单独交给用户选择的 Gemini 实施。仅当 P1-T01–T03 均由阶段控制记录 PASS，且实际文件与 T03 交付指纹一致后执行。P1 阶段控制验收本卡和 P1 集成，总控再独立总验收。

## 目标、依赖与文件所有权

目标：沿用用户认可的 PC 布局，在 `npm start` 页面提供“接入已有项目”向导，再展示真实 Git 只读源码状态；`npm run preview` 保持纯演示。安装包/升级包仍清楚标注演示。此卡不实现本地 Git 初始化、克隆、fetch/pull、提交/推送、切换分支、材料关联或手机端。

开始核对 T03 PASS 记录、实际 SHA-256、P1 原件 manifest、`git status --short --branch` 和适用 `AGENTS.md`；不明变化先停覆盖。阅读 `docs/stages/P1/STAGE_PLAN.md` 第 3–9 节及本卡。允许写 `frontend/index.html`、`frontend/app.js`、`frontend/styles.css` 的必要部分、根 `README.md`、新建 `docs/P1_DELIVERY.md`。为服务返回固定真实模式标记，可顺序小改 T01–T03 的 `server/` HTML 入口；不得改 Git/配置语义。`preview.mjs` 原则上不改；若为保留演示入口确需小改，先说明原因并证明 P0 行为。不得写总控文档、本目录阶段文件、业务仓库或材料目录。共享入口只在前卡 PASS 后接手，不并行修改。

## 接入向导的 PC 行为

- 首页已有项目可选，并有“接入已有项目”；无项目时显示入口与简短说明。第一版让用户**输入/粘贴本地绝对目录**，不承诺浏览器原生任意目录选择器，也不提供全盘浏览或远端 URL 输入。告知不会改原项目，只在确认后保存本工具登记。项目名称可编辑；内部 ID 用浏览器安全随机数生成符合 `[a-z][a-z0-9_-]{0,31}` 的候选值（如 `project-` 加 12 位十六进制），冲突时提示并生成新候选，不让用户为技术 ID 卡住。
- 点击“检查目录”才向 `POST /api/projects/inspect` 发送路径；使用同源 JSON、`X-Local-Intent: project-onboarding`。检查失败、返回错误或取消时不调用确认，不保存；说明无效路径、非 Git/bare 目录不支持本阶段接入，不暗示会运行 `git init`。空 Git 仓库可继续，明确“尚无提交”；本地代码目录若无 Git，提示后续可主动初始化，但本阶段无此按钮。仅有远端 URL 的克隆也留待后续。
- 检查成功显示服务端解析的 `repositoryRoot` 供本人核对；子目录输入的根目录变化必须醒目。摘要显示当前分支或分离/未出生状态、最近提交或无提交、未提交变更文件数、相对本地上游引用的 ahead/behind 或未知，并标注“本地跟踪快照，未联网核实”。明确告诉用户已有历史、尚未提交/尚未推送的工作都会保留，不以远端覆盖本地。材料目录可稍后关联；页面材料区现仍是演示。根路径仅在本机确认界面显示，不带进普通项目列表/日志或截图中的共享材料。
- 只有用户点击“确认接入”才用 `inspectionId`、名称和候选 ID 调 `POST /api/projects`，请求不重发目录路径。确认中禁重复点击；服务端已登记返回 `alreadyRegistered:true` 时选中已有项目，不显示为新建；成功后刷新项目列表并进入工作台，重启可再选。票据过期/身份变化提示重新检查，不自动提交新的登记。保存失败要保留页面输入和明确错误，不报成功。旧请求不得覆盖用户切换后的项目或新一轮检查结果。

## 真实源码页与模式隔离

- 共用 `index.html` 放默认演示模式标记，`npm run preview` 原样提供；真实服务仅对返回的 HTML 设置固定真实模式标记、不写回源文件，前端启动时读取。不根据 API 失败猜模式，也不失败后回落虚构数据。正式入口请求项目列表、source/history；错误显示具体可理解提示与重试。没有配置时显示接入入口，不要求用户首先手工改 JSON。
- 展示项目名、当前分支或分离/未出生状态、`changedCount` 和 `changes` 的新增/修改/删除/重命名/冲突、`oldPath`。25 格仅提醒并沿用现有颜色阈值，超过 25 显示真实总数；暂存和未暂存同文件只算一项。真实“查看改动”仅列路径和状态，不显示演示差异或文件内容。
- `upstream.state=available` 才展示 ahead/behind；`not-configured`/`unavailable` 显示无上游/未知，不能写 0 或已同步。远端跟踪引用标明本机快照，本地上游按本地引用解释；`scannedAt` 是本地扫描时间，不是远端刷新。空仓库、分离 HEAD、冲突、Git 不可用不伪装已同步。
- 历史图根据 API 的 `oid/parents/refs` 画真实父子边，显示本地分支、远端跟踪引用、标签和当前 HEAD；合并有多父边。窗口外父 OID 标示未加载，不能连错行或画成版本起点；`truncated` 提示“仅展示最近 100 条可达提交”。空仓库说明无提交。文件名、提交信息、引用名与项目名均按文本安全渲染，不注入 HTML。保留原表格、卡片、颜色和 PC 版式，不用演示固定行号套线。
- 真正只读模式隐藏/禁用模拟提交、模拟推送、场景切换和演示 reset，事件处理层也不可触发模拟动作；“刷新”只重读本地，不 fetch。材料两区即使在真实入口仍标示“演示”，不能假称为当前项目材料。`frontend/index.html` 原 meta CSP 的 `connect-src 'none'` 调为同源 `connect-src 'self'`，不开放外域脚本/连接。
