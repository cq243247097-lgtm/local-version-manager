# P3-T01 任务卡：本地提交候选与可信预览

将**本卡单独**交给 Gemini。模型由用户选择。阶段主控负责本卡审核，原总控负责 P3 大阶段独立验收。任务仅在本工具中实现首批**本地提交预览**，不调用会改变被管理仓库的 Git 命令；不要自行实施 T02–T04。开始前读取 `docs/stages/P3/STAGE_PLAN.md` 第 1–5、7 节与 `docs/P3_STAGE_CONTROL.md`，报告当前目录、`git status --short --branch`、适用 `AGENTS.md` 和接收哈希。

## 目标、非目标与前置

前置证据：`docs/acceptance/P1_R01_FINAL.md`、`P2_R01_FINAL.md` 均 PASS；用户已选首批只做本地提交；`.local/baselines/P3/manifest.json` 保存无提交仓库基线。本卡实现从已登记仓库的真实状态构造**文件级候选和服务器可信预览**，显示/返回可审查的提交范围、无法支持的原因与短期确认票据。只用临时仓库探针验证将来采用的 Git 选择路径语义；不要实现实际确认、提交、HTTP 路由、真实页面或远端能力。

## 文件所有权

允许新建 `server/git/commit-preview.js` 及直接对应的 `tests/git_commit_preview.test.js`；如确有必要，可新建同目录仅供预览使用的辅助模块。**不修改** `server/git/exec.js`、`status.js`、`inspect.js`、`server/app.js`、`security.js`、`config.js`、`frontend/*`、`preview.mjs`、`README.md`、P1/P2/总控文件及真实业务/材料目录。若当前只读解析不足以安全提供候选，先在独立新模块重读必要 Git 事实；需要改共享只读模块时停下说明最小改动，不擅自扩权。测试夹具只在系统临时目录。

## 必须交付的契约

1. 从调用者提供的**已登记项目 ID 对应仓库根**与当前 Git 状态读取候选；模块本身也复核工作树根、common-dir、附着本地分支、HEAD、索引身份。不得用浏览器传来的任意路径作为仓库根。候选一条对应精确文件或一组重命名旧/新路径，提供稳定短期 ID、路径、旧路径、暂存/未暂存类别、操作类别与不可选原因；不把目录当文件提交。文件名支持中文、空格、前导 `-` 与 Git 特殊字符，用 NUL 分隔和字面路径，不拼 shell 字符串。
2. 预览输入仅为选中的候选 ID 数组和单行非空说明；说明设明确长度上限，拒绝换行/控制字符、重复或未知 ID、空选、过量选项。**选中路径当前工作树内容**才是提交内容，未选文件包括已暂存文件都不属于预期提交树。选中路径若有暂存与未暂存两版，拒绝并解释；删除/重命名/未跟踪按独立类别说明。拒绝冲突、合并/挑拣/变基中、分离/未出生 HEAD、子模块/稀疏检出、特殊文件、无法确认安全的仓库配置；这些拒绝不得改动仓库。
3. 预览从 HEAD、真实索引、精确选中工作树状态计算预期树/变更摘要与有限大小的差异概览，标明超限或二进制内容；不能只把 `git status` 当前计数当实际提交内容。票据高熵、有限 TTL、绑定项目 ID、仓库根和 common-dir、分支 ref、HEAD OID、索引指纹、选中路径及内容/类型、预期树、说明。票据不持久化，重启过期；不返回任意文件正文或仓库绝对根给普通状态接口。提供 T02 可调用的“确认前重新计算并比较”函数，差异返回 `PREVIEW_STALE`，不写 Git。
4. 冻结支持配置门槛：有效提交 hook 或 `core.hooksPath`、启用签名、外部 fsmonitor、适用路径的外部 filter/clean 程序、无法安全判明的扩展一律拒绝，并提供可读原因；缺 author/committer 身份报 `IDENTITY_MISSING`，不设置 Git 配置或启动签名、凭据、编辑器。只读检查仍不得触发 fsmonitor/hook/filter。T02 写执行器必须独立实现，不复用 `runGit` 的全部只读配置。
5. 在临时 Git 仓库做**定向 Git 原生命令探针**并记录：`commit --only` 对已暂存未选文件、选中普通修改/删除/重命名、未跟踪新增的实际行为，尤其是否必须先对未跟踪执行精确 `git add`；不得用本工具仓库试提交。若 `--only` 无法实现上述承诺，**停止生产实现**，把探针事实和最小替代方案交阶段主控裁决。探针临时文件清理须限定已核对的临时绝对路径。

## 定向验收与停止条件

用隔离仓库覆盖：选中/未选中暂存并存、同一路径部分暂存阻止、未跟踪、删除、重命名、中文空格及前导 `-`、冲突、未出生/分离 HEAD、空树/空说明、身份缺失、hooks/签名/fsmonitor/filter、预览后 HEAD/索引/选中内容改变、票据过期/重启。对每个预览前后核对仓库 HEAD、索引字节、工作树文件和配置不变。执行 `node --check`、本卡定向测试；全量测试只在有必要确认共享回归时运行，报告真实计数。不要读取或提交真实业务仓库。

Gemini 停写后向用户交付：变更文件与前后 SHA-256、探针命令和结果、测试命令/计数、仓库未被预览修改的证据、未验证平台/场景、`git status --short --branch`。若需要修改未授权文件、无法安全确认 Git 语义、测试产生真实仓库写入或出现无法解释的暂存差异，立即停止相关实施并报告阶段主控。T01 通过前不能自行开 T02。
