# P4-T03：材料操作专用安全 API

状态：依赖锁定。前置：T01/T02 核心独立 PASS；工厂接口冻结。目标：接入已有 HTTP 服务，核心只经工厂执行。

允许修改 server/app.js；必要时 server/security.js（不削弱旧语义，优先原样复用 validateAndParseJsonPost）；新增 tests/materials_operations_api.test.js、docs/stages/P4/P4-T03_IMPLEMENTATION.md。既有 API 测试只有直接契约修正时列明后顺序修改。禁止 Git/材料核心、配置 schema、frontend、README 和总控文档。

新端点统一在 /api/projects/:projectId/materials/:kind/operations 下：
- POST /preview：严格白名单 {action,relativePath,baseline?,targetRoot?}，targetRoot 仅 archive 必填；baseline 仅 {sha256,source}
- POST /confirm：严格 {ticketId,operationId}
- GET /:operationId：只查询，不恢复写入
- POST /:operationId/cancel：严格空对象 {}，明确协作式取消/已完成事实

所有 POST 必须 Origin 精确同源、X-Local-Intent: material-operations、JSON、8 KiB、字段/长度/枚举校验；global Host/Sec-Fetch-Site 保持不变。方法不符 405；恶意输入安全拒绝发生在新建操作记录/目标前。源只能来自已登记 projectId/kind，relativePath 为关联根内规范相对文件，拒绝绝对、..、反斜杠/平台设备名等；不能接受命令、外部 URL、源根或 arbitrary 参数。

createRequestHandler/createAppServer 添加可选 materialOperationsDir，仅用于受信启动参数；默认派生自 configPath。每 handler 创建一次工厂，不能逐请求丢失票据/取消句柄。工厂自己重查配置，避免将长时间 hash 锁住现有全局 config lock；与配置变更的保护依赖绑定核对而非假定无外部写者。

DTO 明列允许字段，不直接序列化 ticket/store/异常对象。合法预览可回显用户输入的目标摘要以便确认，但不得额外泄露源码根、配置路径、原始系统错误、堆栈或任意文件内容。响应区分 HTTP 错误与操作真实状态，unknown 必须带原 operationId 查询指引；完整性 mismatched 不是传输失败亦不是校验成功。query 的旧关联结果必须保持绑定，不可当新根结果。

覆盖：完整闭环/取消/重复/重启、未登记/缺关联、跨项目 kind 和配置替换；所有 headers/method/body/超限拒绝；两请求并发，记录及复制故障真实 DTO；P1/P2/P3/静态白名单回归。交付完整请求/响应样例及字段契约，node --test tests/materials_operations_api.test.js 和相关 API 回归，停写经独立 PASS 后解锁 T04。

共同停止条件：接收指纹或写入者不明、需越过分配路径/安全边界、出现真实材料/仓库写入需求、无法保护源/旧目标、需修改接口语义或无权限操作时，先停受影响工作并向主控报告具体对象与原因。完成本卡后停止写入，不自行解锁下一卡、不提交或推送。验收由主控指定的独立审核者进行；阶段/最终结论由总控维护。
