## 顺序检查

1. 新程序目录 npm start；另终端 npm run preview。4189 真实、4191 演示，空配置如实显示。Ctrl+C 正常停止；无关 cwd 通过入口绝对路径启动成功。
2. 接入临时仓库先检查后取消，应不登记；再次确认后状态/历史正确，源文件与暂存内容不变。刷新/重启后登记保留。
3. 只选待选文件，预览取消应零写入；确认并重复点击只产生一个提交。核对未选暂存仍在且不混入提交。预览后改文件，旧确认必须拒绝。
4. 分别关联临时安装/升级目录；扫描不改材料。未声明来源或兼容性时保持未知，不显示安装通过。
5. 无基准摘要显示 no_baseline；主动输入正确 SHA-256 和来源显示 matched，错误摘要显示 mismatched。历史查询不重新计算，修改源后不能说当前仍匹配。
6. 独立归档目标预览后取消不复制；确认后源保留、副本存在。同内容 duplicate，不同内容同名目标 conflict，旧目标字节不变。工具数据/源码/材料内目标应拒绝；基准不匹配不发布；不支持安全硬链接必须 unavailable，不降级覆盖。
7. 记下原 operationId。关闭/刷新后“查询上次材料操作”恢复；断线/重启只查原 ID。移走临时材料后仍能查看历史且不宣称当前关联有效。未知/部分完成保留现场，不用新 ID 重做。关闭对话框不等于取消；运行中取消应披露实际发布事实。
8. 使用空格/中文路径、临时无权限目录、Windows junction 与已有目标，核对拒绝危险路径并保护原件。不降低系统安全设置。
